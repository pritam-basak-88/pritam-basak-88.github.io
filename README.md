# Pritam Basak Portfolio — V2

A light-peach, premium executive portfolio inspired by the supplied reference image.

## Files
- index.html
- style.css
- script.js
- profile.jpg  <-- add your actual professional photo
- Pritam_Basak_Resume.pdf <-- add your actual resume

## Publish
1. Open repository `pritam-basak-88.github.io`
2. Upload all files to the repository root.
3. Commit changes.
4. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
5. Wait a few minutes and open `https://pritam-basak-88.github.io/`.

## Important
Replace `profile.jpg` with your actual professional photo. Keep the filename exactly `profile.jpg`.
Replace `Pritam_Basak_Resume.pdf` with your actual CV using the exact same filename.
