# Pritam Basak — Professional Portfolio

GitHub Pages-ready personal portfolio.

### Structure
- `index.html`
- `style.css`
- `Pritam_Basak_Resume.pdf`
- `assets/profile.jpg`

### Publish
Upload these files to the root of `pritam-basak-88.github.io`, keeping `assets/profile.jpg` inside the `assets` folder.

Then GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
